# 公开版范围

本版本以 2026-10-06 的已提交系统代码为起点，使用新的 Git 历史发布。原私有仓库与本地未提交工作保留；本次不部署生产服务。

## 包含

前后端源码、测试、API 契约、配置模板、设计文档和运行所需的前端素材。新增展示图注明生成来源，界面截图注明真实捕获来源。既有前端素材的公开再分发权限由操作员确认。

## 排除

客户手册及其打包字体、交付归档、生产数据库、API 密钥、个人工作区文件、旧提交历史与服务器实例标识。配置模板不包含可用凭据。生产页面与数据不会因为代码开源而获得再分发授权。

## 演进

公开版将大型模块拆分、上下文装配与数据访问边界作为后续维护方向。详见 [代码审查](code-quality-review.md)。本次保持预测语义与后端契约不变，合并前端重复的请求等待期限实现，并修复视觉测试的旧等待条件与手机模拟。公开配置支持首次提交检查；展示图片使用独立大小上限，代码文件大小门槛保留。
