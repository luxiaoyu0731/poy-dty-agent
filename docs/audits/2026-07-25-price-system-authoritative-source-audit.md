# 价格体系与权威源对比审计

审计日期：2026-07-25
范围：原油、石脑油、PX、PTA、MEG、POY、DTY；项目有记录以来的价格数据、数据源、单位与规格口径、时间边界、历史曲线、最新价覆盖与页面表达。
审计方式：只读检查生产数据库、授权 CCF 采集文件、后端与前端链路，并与公开一级源及 CCF 授权记录交叉核验。本报告未修改数据或代码。

## 一、结论

当前页面不能被解释为一套统一的“CCF 上游原料价格体系”。

截图中的七个最新价混合了：

- Yahoo 的 Brent 期货连续合约代理价；
- TradingEconomics 的石脑油公开 CFD/估值；
- 新浪的 PX、PTA、MEG 主连期货代理价；
- Texnet/生意社页面的 POY、DTY 非成交型公开估值。

与此同时，历史曲线采用 CCF 日均现货/期货序列，页面却把不同来源、市场、规格、币种和时间频率的“最新价”覆盖在历史卡片上。它们可以分别作为监控信号，但不能并排后被理解为一条同口径产业链，也不能直接计算价差或成本传导。

总体评级：**不适合用于正式成本传导判断，需先完成口径重构。**
数据本身并非全部错误；主要问题是“正确的 CCF 历史 + 不同口径的公共最新价”被组合成了误导性的统一价格链。

主要问题：

1. 原油曲线截至审计日滞后 36 天。截图所写“262 个交易日”正是这条停在 6 月 19 日的 CCF Brent 历史；卡片上的 7 月 24 日最新值来自 Yahoo。即“最新点”和“历史曲线”不是同一序列。
2. 六个产业链 CCF 主序列联合日期共 408 日，但各序列分别缺 18–33 日。任何相关性或成本传导计算必须先按共同日期对齐并披露有效样本数。
3. POY/DTY 阶梯报价特征明显。切片纺 POY 部分序列相邻日持平率达 68%–74%，不能把每个日期都当成新的独立市场信息。
4. CCF 核心序列没有发现同一产品、规格、日期的重复，也没有未来日期或 `created_at` 早于 `observed_at` 的情况，这是现有数据治理中的正面控制。

### 3.2 必须复核的异常簇

2026-03-09 出现唯一一次至少五个品种同时单日绝对变化超过 10%：

- 石脑油 +27.71%
- PX +24.75%
- PTA +22.76%
- MEG +12.80%
- POY 150D/144F +26.81%
- DTY 150D/144F +26.65%

次日 Brent、WTI、石脑油、PX、PTA 又分别下降约 11%–15%。该簇可能对应真实重大市场事件，也可能是批量口径/日期错位；在复核 CCF 原始页面或导出前，不能断言其为错误，也不能让它无审查地进入相关性、回测或模型训练。

### 3.3 命名、重复与单位治理

- CCF 的 PX 出现 `CFR中国PX` → `PX CFR中国` 命名漂移；石脑油出现 `CFR日本石脑油` → `日本石脑油`，且切换期存在重叠。若不做 alias 归一化，可能断线或双计。
- `market_observations` 有三组精确重复导入，每组重复三次：2026-06-01 WTI、2026-06-05 美元指数、2026-06-08 美国 10 年期国债收益率。它们会污染按行计权的统计。
- 外部现货表中 `CNY/mt`、`RMB/ton`、`元/吨` 同义单位并存，同时混合 benchmark、范围中点、报价与现货评估，不能只按 `product` 拼接。
- PX/石脑油历史用 FRED `DEXCHUS` 进行 USD/mt → CNY/mt 折算，最多向前结转 7 日。该计算只完成币种折算，不包含关税、增值税、港杂、运费或交割升贴水，不能标成“国内到岸成本”。

## 四、系统链路问题

### P0：公共代理价覆盖 CCF 最新展示

- 后端在 `/server/app/main.py:2554` 附近用 intraday observation 覆盖 `latest_display_price`。
- `/server/app/price_intraday.py:30` 附近明确配置 Yahoo、新浪、东方财富、TradingEconomics、SunSirs 与 Texnet。
- 前端 `/src/pages/AgentWorkbenchPage.tsx:2732` 附近优先展示 `latest_display_price/intraday`，CCF canonical 只保留为历史趋势。

结果：用户选择了 CCF 作为业务价格源，但顶部节点显示的并不是 CCF。

### P0：历史 `as_of_time` 回放存在时间穿越

市场工作台先用全库最新数据计算摘要，再裁剪历史 `price_series`，没有全面重算 latest、freshness、spread 与 coverage。部分节点在历史时点回放时可能保留截止时间之后的摘要。

此外，intraday 查询先按品种取全库最新一条，再过滤是否早于 cutoff；如果最新一条晚于 cutoff，系统会显示缺失，而不是回退到 cutoff 前最后一条有效观测。

### P0：错误抓页数据已经入库

DTY 公共抓页共 4 行，其中两行明显错配：

- `2026-07-10 = 2026 CNY/mt`：把年份解析成价格；
- `2026-07-22 = 16,400 CNY/mt`：抓到了锦纶/其他产品附近数值。

展示层的产品身份检查能屏蔽部分坏行，但“先取最新、后校验”的逻辑会让坏的最新行遮蔽此前有效行。数据库仍保留污染记录。

### P1：UI 没有充分表达权威等级与口径

后端知道 `spot_public_valuation` 是非成交估值，也知道主连期货是代理价；截图的链节点却主要只显示品种、数值、单位与时间。缺失：

- source/source tier
- spot/futures/valuation
- contract/spec
- market/region
- tax/freight basis
- original currency 与 FX date

### P1：模型与导入约束不足

价格模型对 product、unit、quote type 多使用自由字符串；没有强制：

- `price > 0`
- `price_low <= price <= price_high`
- 产品与单位/市场的白名单组合
- 规格、等级、税费和运费口径
- 日变阈值与人工复核状态

当前宽松的合理区间不能防止“年份被解析为价格”或“同页面邻近产品串值”。

## 五、正确的基准体系

建议把“业务 canonical”与“监控 proxy”彻底分层：

| 品种 | 业务 canonical | 监控/交叉验证 |
| --- | --- | --- |
| 原油 | 明确选择 EIA Brent/WTI 现货，或 CME/ICE 具体期货合约；二选一，不写泛称“原油” | Yahoo 连续合约仅作实时监控 |
| 石脑油 | CCF 日本石脑油，保留 USD/mt 与原始报价机制 | TradingEconomics CFD 仅作报警 |
| PX | CCF PX CFR 中国，USD/mt | 大连商品交易所具体 PX 合约仅作期货信号 |
| PTA | CCF 内盘 PTA 现货日均 | 郑商所具体 TA 合约/官方结算 |
| MEG | CCF 内盘 MEG 现货日均 | 大连商品交易所具体 EG 合约/官方结算 |
| POY | CCF，固定地区、等级与规格，例如 POY 150D/144F | 公开报价页仅作偏差报警 |
| DTY | CCF，固定地区、等级与规格，例如 DTY 150D/144F 轻网 | 公开报价页仅作偏差报警 |

CCF 自身将其服务描述为覆盖聚酯产业链价格、负荷、库存、效益等数据，并提供价格指数；这支持把 CCF 作为聚酯与化纤业务口径，但不能省略具体系列与规格。参考：[CCF 服务体系](https://cnc.ccf.com.cn/service/webser.php)、[CCF 数据中心](https://www.ccf.com.cn/datacenter/price.php)。

每条可比较序列的唯一键至少应为：

`product + market/region + spec/contract + quote_type + currency/unit + tax/freight basis + delivery window + source`

任何字段不同都不得拼成同一条曲线或计算直接涨跌。

## 六、整改优先级

1. **立即停止把公共 intraday 值覆盖为 CCF 最新价。** 页面提供“CCF canonical”和“实时 proxy”两个并列但视觉分层的值。
2. **固定七个业务 canonical 系列。** POY/DTY 必须明确规格；原油必须明确 Brent/WTI 与现货/期货；PX 必须保留 CFR 中国和 USD/mt。
3. **修复 as-of 回放。** 所有摘要在 cutoff 后重新计算，并按 cutoff 查询最后一条有效 intraday。
4. **隔离坏数据。** 将 DTY 两条错配记录标为 rejected/quarantined；校验应在入库前执行。
5. **对 2026-03-09/10 做 CCF 原始证据复核。** 通过前不得进入模型训练或正式回测。
6. **统一 alias 和单位。** 同义命名映射到 canonical ID，同时保留原始名称；显示原币种、FX 日期与汇率。
7. **补齐数据契约。** 强制规格、市场、报价类型、币种、税费/运费基础、交割窗口、来源等级和修订版本。

## 七、限制

- CCF 为授权商业源；本报告没有复制其完整付费历史，只核验项目工作区中已有的授权采集和导入记录。
- 公开来源无法替代 CCF 对 POY/DTY 等细分规格的价格定义。
- 本次是审计报告，不包含数据修复、代码修改或页面改版。
