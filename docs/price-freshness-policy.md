# 价格时效与口径策略

本系统面向个人研究，不是交易终端。所有价格必须显示口径、时效和来源层级。

## 价格层级

| 层级 | `price_type` | 说明 | 前端显示 |
| --- | --- | --- | --- |
| 交易所/代理分钟行情 | `exchange_proxy` | 例如 Brent/WTI 公开代理分钟行情 | 交易所/代理行情 |
| 近实时公开行情 | `near_realtime_public` | 例如东方财富 PX/PTA/MEG 主连公开行情 | 近实时公开行情 |
| 延迟或日频参考 | `daily_reference` | EIA/FRED 或官方日行情 | 日频历史价格 |
| 公开现货评估 | `spot_public_valuation` | SunSirs/Texnet 等页面公开评估价 | 非成交型现货评估价 |
| 人工/慢队列 | `manual_slow_queue` | Computer Use 或 CSV 手工整理 | 人工/慢队列 |

## 时效标签

| 条件 | 标签 |
| --- | --- |
| 2 分钟内 | `2分钟内` |
| 15 分钟内 | `15分钟内` |
| 1 小时内 | `1小时内` |
| 超过 1 小时 | `已延迟` |
| 公开现货评估价 | `公开现货评估` |
| 没有观测 | `暂无分钟级观测` |

## 品种口径

- Brent/WTI：公开代理分钟行情，可作为原油端近实时参考。
- PX/PTA/MEG：优先使用 Sina 主连公开代理行情；东方财富作为备用核验；SunSirs 作为公开现货评估参考。
- POY/DTY：只能标记为“非成交型现货评估价”或“人工/慢队列”，不能标记为分钟级成交行情。

## 展示原则

每个价格节点必须展示：

- 价格
- 日期/时间
- 变化幅度
- 单位
- 时效
- 口径
- 是否为成交/代理行情

缺数据时显示“等待采集”“来源不可用”或“需要人工确认”，不要显示 `--`。
