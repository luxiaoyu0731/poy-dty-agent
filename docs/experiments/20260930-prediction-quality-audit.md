## A1 石脑油历史点（36→60）

**回填可行性**：源页 `zh.tradingeconomics.com/commodity/naphtha` 只展示当日估值句（payload quote 仅含一个日期），无历史表 → 现有注册源无法回填。intraday 表也只有 44 行（07-23 起）。更早历史需注册新源（授权+标签治理）。

**所需授权**：无（等待）；提前到位=新历史源注册（需授权，不建议）。

## A2 crude stale（已修复待发布）

**根因**：Yahoo chart API 对 `BZ=F` 返回 **HTTP 429**（限流）。2026-09-30 00:01 UTC 导入 summary 明确记录 Brent/RBOB/ULSD 三符号 429，同轮第一个请求 WTI 成功（数据到 09-29）。Brent 标签止于 09-25（09-26 09:19 UTC 手动运行补齐 09-24/25 后，每个 08:00 定时运行 Brent 均失败）。
**影响**：① crude 三格 degraded；② ≥09-27 批次（v5 期货标签）crude 结算全部 `pending_maturity`（结算需 target date 之后的标签行）；③ ≤09-26 批次（v4 EIA 身份）等待 EIA 周度发布（市场行最新 09-22）。结算 dry-run（apply=False）确认 0 blocked、纯 maturity 等待，标签恢复后下一个 08:00 运行自动清空积压。
**修复（diff 已就绪，本地测试通过）**：`server/scripts/import_trade_futures_proxy.py` —— 429/5xx 有界重试（4 次，尊重 Retry-After，5s 指数退避封顶 30s）+ 符号间 2.5s 间隔。测试：`tests/test_import_trade_futures_proxy.py` 5 passed；相关面 46 passed。
**效果**：crude 三格回 reference（评分不变），正式资格路径重开；结算解堵。**所需授权**：部署发布（narrow release 流程）。

## A3 信号因子（MEG/POY/DTY 恒 0）

**结论：σ 窗口假设不成立。** σ 估计已用全部 LOOKBACK=120 点（非短期窗）；且 MEG/POY 的中位日收益**恰好为 0**（MEG 81 日中 33% 零变动+分布对称，中位数=0）→ predicted_change=0 → 任何正带宽下都是 neutral。带宽变更无法产生信号（E1 结论一致且更强）。
**DTY**：60 点窗中位 +0.0823%/日 → 30d chg +2.50% > band 2.36% 会出信号；120 点窗中位=0 无信号。窗口是模型参数，样本内最优不可上线；需回放验证且多时段复现。
**附带重大发现（POY 历史坏行）**：tnc 回填历史含 2026-04-23=887.5（疑似 8875 小数点错位）、2026-03-18=15625（疑似规格混入）等。旧合约（≤09-26 批次）σ 被污染至 ~30%/日（1d band=15%）；**issue-calendar.v1 的 causal-quality-quarantine（JUMP_RATIO=1.35，prediction_replay.py:133）已自动隔离坏行**（09-27 起 band 0.94-1.5%）。无需行动；已结算历史不可改写（immutable）。
**方案（待授权）**：漂移估计量从中位数改为截尾均值/EWMA 等是唯一能让三品种出信号的杠杆——属模型版本变更，需注册、隔离回放验证、门槛重评。B2 证据支持方向信息存在（见下），但幅度优势未证明。
