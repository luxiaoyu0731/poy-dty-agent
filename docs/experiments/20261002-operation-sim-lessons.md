## 目的

操作员指令：模拟系统"像真实运行了小两年"——2025-01-01 → 2026-09-01 逐日隔离
运行，并让复盘校准的反思模块（结算 → 周蒸馏 → 教训注入政局解读/历史经验）
真实转动；A/B 对照组关掉反思循环，同一日历逐日复刻，归因反思模块的价值。

## 配置保真

- 逐日水印隔离（与前日 23:59 截断，与 25y 基准同纪律）；预测 = 事件日次晨 08:00
- 生产口径：每日 top-16 候选、预算 16/8/7/7/2、安静日按纯价格发牌、D1/D7/D30 到期结算

  活跃教训上限 30，注入带 lesson_id 引用约束
- 两组 421 天、266 个链日、1263 格结算，完全配对；基线命中率 21.38% 两组逐位一致（隔离完整性自证）

## 运维决策（周一前必须定）

**生产蒸馏定时器 `poydty-distill.timer`（周一 09:05 首跑）建议暂停**，直到
反思循环重设计并通过同类 A/B：节点 B 现在就会注入活跃教训，周一首蒸会把
同一有害机制带进真实发牌链。暂停 = `sudo systemctl disable --now
poydty-distill.timer`（操作员决定）。

## 重设计方向（下一轮）

1. 蒸馏语料只看"改写格"（R2 切换样本的成败），不蒸馏全部格——教训应回答
   "何时该改写"，而不是"方向判断总命中率高不高"
2. 先修结算口径：D7/D30 的中性带按期限分档（0.5% 是 D1 带宽），否则命中
   信号失真会继续污染每一轮蒸馏
3. 教训注入降权为"背景提示"，不进方向指令段
4. 验收门沿用本实验：教训组必须赢对照组才准进生产——本实验就是这门，它
   正确地拦下了一次坏导入
