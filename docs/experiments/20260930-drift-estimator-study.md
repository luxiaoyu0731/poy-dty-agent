# 漂移估计量隔离回放 — 立项评估结论（2026-09-30）

方法：对账本 311 个已结算样本（点时纪律：仅用原点观测日之前历史），在同一历史窗口上
对比 5 种漂移估计量的方向命中率：中位数（现行）、截尾均值 10%/20%、EWMA（半衰期 20/40）。

## 结果

| 估计量 | 命中/配对 | 率 |
| --- | --- | --- |
| 中位数（现行） | 178/311 | 57% |
| 截尾 10% | 177/311 | 57% |
| 截尾 20% | 177/311 | 57% |
| EWMA20 | 176/311 | 57% |
| EWMA40 | 177/311 | 57% |

逐格差异 ≤2 格（meg 7d −1、crude 7d ewma20 +7 但绝对值仍 30% 远低于 55% 门槛、
px 7d ewma20 −5）。在 n=311 的配对集上，任何两种估计量的差异都在样本噪声内。

## 结论

**不立项。** 漂移估计量替换在现有数据规模上没有可统计显著的改善空间——这与方法论审计
（中位收益恰为 0 是 MEG/POY/DTY 信号因子为 0 的根因）一致：当时间序列近期无净漂移时，
任何中心估计量都返回 ~0，改估计量无法凭空创造信号。

建议的后续检查点：2026-12 样本翻倍后用 `scripts/experiments/replay.py` + 本研究脚本重跑；
若届时任一估计量在配对检验中显著优于现行（p<0.05），再立模型注册变更。
