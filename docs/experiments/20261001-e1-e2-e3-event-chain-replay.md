事件链保持影子模式，晋级以生产影子期为准（ADR-6）。

必须记录的口径限制（读数字前先读这四条）：
1. 回放结算用固定 0.5% 窄带 + point-in-time 价格，**实际方向多数非中性**，
   永远中性的基线命中率被压到 ~22%；生产 OOS 用 robust-σ 宽带（中性更多），
   两口径绝对值不可直接对比，本实验价值在**同带同样本的 A/B 增量**
2. D30 为截断结算（见上）
3. E3 为新近性切分（见上）
4. 单次窗口 16 个有效日（事件库 09-07 起步），n=336 达到 §7.1 的 ≥200 目标，
   但跨行情区间的稳健性未测
