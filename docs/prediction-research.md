# 预测体系研究与可重复评估

当前入口是离线研究工具，不接管生产 21 格，也不改写旧预测/结算。设计依据与候选体系见 [ADR](adr/20260926-prediction-replay-research.md)。

## 执行顺序

1. **数据质量**：核对来源、语义序列、单位、数值、原文证据哈希和完整性；选定历史版本后，再做仅用此前报价的可疑跳变隔离。原记录不变；最新价可疑时不发报。统计隔离不是“已证明源数据错误”，真实市场跳变仍需核对。
2. **历史时点重放**：每个上海时间 09:30 只使用此刻已可见、已捕获、已入账的版本。晚补历史可以用于补入后的训练，不能虚构补入之前的预测能力。完整修订列表不能替换成今天的最终快照。
3. **统一合同**：比较发报日后 1/7/30 日历天与后续 1/5/20 次报价。后者不是保证 1/5/20 天到期。方向相对于发报时最后有效价计算，报价年龄单列；这不等同于从不可观测的“发报瞬时真实价格”起算收益。同一品种使用固定涨跌阈值，模型不能自己定义其答案是否正确。弃权与中性分离。
4. **对照与校准**：冻结四个数值模型及过去类别频率基线；同时报告永远猜涨/跌/平的固定基线。校准只使用已到期、已可见且时间段不重叠的过去结果；这些样本并不因此获得统计独立性。样本不够则概率为空，不能把手工置信分数包装成正确率。

## 命令

生产导出需具备只读诊断授权。导出器只读连接、使用读事务与查询时间上限，每源最多 20,000 条，超限拒绝输出；不迁移、不下载原文、不调用模型、不复制整个数据库。文件应放在仓库外。

```sh
cd /path/to/agent/server
python scripts/export_prediction_vintages.py --as-of '2026-09-26T10:26:27.952148+00:00' > /external/vintages.json
```

离线计算只需要 JSON，不需要数据库、联网或生产凭据。输出路径必须是新文件。

```sh
cd /path/to/agent
server/.venv/bin/python server/scripts/run_prediction_benchmark.py \
  --input /external/vintages.json \
  --output /external/benchmark.json \
  --start 2026-07-01 --end 2026-09-26
```

输出含：配置及输入哈希、每时点输入哈希、原报价、各模型预测、首次合格结果、校准样本哈希、质量隔离记录、按品种期限的对照与覆盖率。`pending`、`outcome_timeout`、`outcome_quality_blocked`、输入 `blocked` 分别表达。回放里的 `blocked` 不代表历史生产故障。

研究阈值固定：POY/DTY/原油 ±0.6%，其他 ±0.8%；不是已获业务认可的最优阈值。日历目标允许报价观察日晚四天、收到晚七天；报价步数任务等待上限为 `4×步数+7` 日。第一份合格到达记录结算，后续价格修订独立标注。避免事后选最终修订作为当时已知答案。

校准的最低样本筛选为 30 个不重叠已到期片段、涨/平/跌各五个、当前预测类别十个；使用加一平滑的混淆矩阵行估计。满足这些数量只是允许估计的条件，不是效果证明。还需用后续样本验证概率、Brier/log loss、校准误差与风险—覆盖率；不作逐次正确率保证。

## 2026-09-26 实测

- 5,723 条记录/修订，七品种、六种期限合同、四个候选；3,696 个回放场景。
- 隔离 POY 15,625 / 887.5 两个可疑历史值及石脑油一条品种不匹配记录。原始记录未删除。
- 09-19、09-23 两个时点，POY/DTY 各恢复十个“只拿今天最新版再回看”会漏掉的历史可见报价。
- 595 个可评分场景、359 个未到期、2,742 个因当时可见历史/新鲜度不足不能发报的场景。重复期限、重复结果和重叠窗口不能当成独立样本累计。
- 原油 D30 稳健漂移命中率 88%，永远猜涨也是 88%，只有两个不重叠片段。不能据此证明高可靠性。
- POY/DTY 当前没有 D30 的合格重放结果；多数品种有效实时证据区间远短于行情曲线历史。
- 当前没有满足校准门槛的组合。代码已实现，生产正确概率尚未验证。
- 117 项预测相关回归通过；Ruff 和 diff 检查通过。本轮未发布、未调用付费模型、未增加依赖、未修改模型注册表。

完整证据：`/path/to/project-context/prediction-system-20260926/REPORT.md` 和同目录 `EVIDENCE_INDEX.json`。

## 第二轮：上游特征、方向分类和延迟反馈组合

离线入口沿用第一轮的原始输入、发报时点和首次合格结果，不改写评分答案：

```sh
server/.venv/bin/python server/scripts/run_prediction_improvement.py \
  --input /external/vintages.json \
  --baseline /external/benchmark.json \
  --output /external/improvement.json
```

新增 `prediction_features.py` / `prediction_improvement.py`：自身及上游价格特征、固定正则化回归、直接涨/平/跌分类、按已到期不重叠片段学习的组合、允许弃权的组合。新模型使用拟合时实际已获得的历史数据；补录历史可以训练，但不能成为过去实时成绩。特征版本v2修正了训练中的报价次数目标：按真实后续报价数取标签，不再折算成天数。日历目标已包含发报时原报价年龄，保持不变。

各候选使用同样的涨跌定义；标准化只用训练集。组合按模型家族分配权重，避免相似趋势模型重复投票。分类器softmax分数、组合一致程度均不解释成已校准的正确概率；不收敛、缺失或样本不足时单独记录弃权。

本轮最终比较14个模型/控制项。预先固定第一组参数；查看结果后增加的同窗口动量控制和直接分类实验明确登记为探索性追加，不当作未见测试。完整保留失败候选。

- 上游信号在相同55个次日场景答对26个（47.3%），旧稳健漂移答对19个（34.5%），恒定价格基线答对23个（41.8%）。覆盖全部140个可评分次日场景的39.3%；其中44个不同实际结果，不是55份独立证据。
- 优势没有普遍成立：POY次日7/15与固定猜涨相同，DTY次日9/21低于旧模型10/21。MEG为5/5，但只有三个不重叠片段，不能宣称可靠。
- DTY次日直接分类11/21，旧模型10/21；09-13后的十个场景二者均5/10，尚无稳定提升证据。
- 两种回归、直接分类的全局表现以及延迟反馈组合均不足以替换旧模型。七日的高命中率还受到单边上涨样本影响；必须对照固定方向基线。
- 置信度校准仍受真实已到期样本限制。新增候选没有生产晋级，现网预测未替换。

最终报告、完整模型对照、期限分层、日期诊断、测试与哈希索引：`/path/to/project-context/prediction-improvement-20260926/REPORT.md`。这组数据已多次查看，下一次效果验证必须保存真正事前生成的预测，不能继续挑选同一批回放中的最高分。
