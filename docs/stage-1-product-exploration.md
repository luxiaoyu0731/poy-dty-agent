# 客户产品使用手册 - 阶段 1 产品探索报告

版本：v0.1（探索稿）
探索日期：2026-07-11
探索对象：`http://127.0.0.1:5173/` 当前客户工作台
性质：内部编制依据，不属于客户手册正文

## 1. 探索结论

当前产品具备编写客户手册的基础，但只能按照真实运行状态制作教程和截图：

- 可作为正常数据态展示：行情与原料链、事件与风险。
- 可作为低置信或部分完成状态展示：总览看板、证据图谱、运行状态、AI 研判助手。
- 可作为真实空状态展示：正式报告、预测账本、到期复盘、证据冲突或筛选无结果。
- 当前不可制作正常案例：正式方向、正式报告正文与下载、非空正式预测账本、已评分复盘。

当前存在真实价格或事件数据，不等于正式研判结论已经形成。正式方向必须通过同一数据快照、真实复核证据、方向推导和置信门禁。

## 3. 实际入口、按钮与操作路径

### 3.1 总览看板

- 主要入口：侧栏“总览看板”。
- 可见动作：“查看数据状态”“查看研判报告”“进入事件与风险”“进入证据图谱”。
- 推荐路径：阅读今日研判状态 -> 检查数据更新与价格观察 -> 查看原料链、事件和证据摘要 -> 进入对应详情模块。
- 当前限制：不得描述正式方向、正式风险、反证或推翻条件已经形成。

### 3.2 行情与原料链

- 品种：POY、DTY、PX、PTA、MEG、石脑油、原油。
- 时间窗口：近 30 日、近 90 日、全部。
- 链路节点可点击切换品种。
- 推荐路径：选择品种 -> 选择时间窗口 -> 阅读最新价与质量状态 -> 阅读成本观察 -> 查看库存、开工、利润及多规格明细。
- 当前限制：单点正式观测与历史多规格均价口径不同时，不生成趋势；POY/DTY 后验价格不是系统预测目标。

### 3.3 事件与风险

- 可用动作：搜索；按全部、原油、航运、制裁、供需、装置、宏观、政策、其他筛选；点击列表查看详情。
- 推荐路径：选择分类或搜索 -> 选择事件 -> 阅读事实、初步方向、影响品种、影响路径、来源和反证。
- 当前限制：事件页方向是事件线索或初步影响，不等于正式成本压力结论。

### 3.4 证据图谱

- 可用动作：“适配视图”“重置视图”“刷新图谱”；关系筛选“全部”“只看支撑”“只看反证”“只看冲突”“只看引用”。
- 推荐路径：阅读判案现场 -> 查看检索与筛选过程 -> 浏览图谱 -> 点击真实节点或关系 -> 阅读采纳、排除或冲突理由。
- 当前限制：证据数必须以截图时同一统一刷新快照为准；图谱关系是研判关系，不等于严格因果。

### 3.5 运行状态

- 可用动作：“刷新状态”；查看 12 个业务环节及输入、输出和状态。
- 当前真实状态：部分环节存在运行记录，其余显示未记录。
- 当前限制：页面产物存在不等于对应 Agent 已完成；不得写服务器、日志、接口或运维状态。

### 3.6 AI 研判助手

- 可用动作：4 个推荐问题；自定义输入和“发送”；“查看证据图谱”“查看研判报告”“重新生成”。
- 推荐路径：选择推荐问题或输入问题 -> 阅读结论与可信边界 -> 核对采用证据、排除材料和冲突 -> 跳转图谱或报告。
- 当前限制：当前回答为降级状态，不构成风险判断、经营建议或执行指令。

### 3.7 研判报告与预测账本

- 二级入口：“研判报告”“预测账本与到期复盘”。
- 报告类型：日报、周报、复盘报告、专题报告。
- 当前报告状态：无正式报告；预览、文件和复制摘要禁用；“查看证据”可用。
- 当前账本状态：0 判断、0 到期、0 等待；可“重新读取”，并进入“证据图谱”或“AI 研判助手”。
- 当前限制：不得描述已有正式预测、准确率、覆盖率、自动落账、自动复盘或自动执行。

## 4. 截图条件

统一桌面视口建议为 1440 x 900、缩放 100%、不含浏览器地址栏。每个模块采用“模块全景图 + 关键面板局部图”。

截图前应：

1. 从总览加载并等待读取状态结束。
2. 通过侧栏切换模块，避免重载瞬间截图。
3. 等待顶栏本地刷新时间和页面内容稳定。
4. 清除悬停、焦点和客户自由输入。
5. 将需要截图的内部滚动面板滚到约定位置。
6. 同一批截图尽量在 5 分钟内完成，并在图注记录截取时点。

建议至少采集：

| 编号 | 页面 | 状态 | 建议截图 |
| --- | --- | --- | --- |
| 01 | 总览 | 低置信 | 全景、今日研判、数据更新、链路/事件/证据摘要 |
| 02 | 行情 | 正常数据 | 全景、产品与周期切换、价格与质量、成本观察、多规格明细 |
| 03 | 事件 | 正常数据 | 全景、搜索分类、事件详情、来源；另拍筛选无结果空态 |
| 04 | 证据 | 低置信 | 全景、判案现场、检索过程、图谱、理由、采用/排除/冲突 |
| 05 | 运行 | 部分完成 | 全景、12 环节流程局部 |
| 06 | AI | 降级 | 全景、推荐问题、回答、引用证据、可信边界 |
| 07 | 报告 | 空态 | 全景、禁用动作、快照门禁原因 |
| 08 | 账本 | 空态 | 全景、边界说明、空账本、空复盘 |

当前不可获取且不得伪造：正式方向、正式报告正文、非空正式账本、可评分复盘。

## 5. 文档与现状不一致项

1. README 仍提及首页拖拽、客户保存预测、数据来源操作台、一键抓取和 CSV 导入；当前客户七模块不提供这些入口。
2. `docs/system-introduction.md` 和 `docs/frontend-manager-workbench.md` 使用旧信息架构，不能作为当前导航教程。
3. 产品总文档仍含旧页面和示例方向/置信度，只能作为愿景，不能当作当前产品事实。
4. `docs/api.md` 的预测请求说明落后于最新服务端复核、方向和置信度门禁。
5. `docs/api.md` 对客户报告的描述包含会被当前客户过滤器排除的运维或质量材料。
6. 架构、Agent schema 和 RAG 索引部分文档存在版本滞后，仅供内部理解。

## 6. 产品问题与优化建议

| 优先级 | 所在范围 | 问题 | 客户影响 | 建议 |
| --- | --- | --- | --- | --- |
| P1 | 证据等级治理 | 产品文档将授权商业数据归为 B 级，但当前 full-chain 中 CCF 授权现货返回 A 级 | 手册无法稳定解释等级，客户可能误解来源权威性 | 在产品和数据治理层统一等级定义；确认前，手册不点名“CCF=A级”，只解释页面显示等级及正式门禁 |
| P2 | 产品文档 | 多份文档仍保留旧导航和客户不可见的内部能力 | 后续维护人员可能写出不存在的教程 | 以当前七模块 IA 为基准同步文档 |
| P2 | API 文档 | 预测写入说明未反映服务端正式方向与置信度推导 | 内部使用者可能误解正式预测合同 | 更新 API 文档，但不写入客户手册 |
| P2 | 截图稳定性 | 证据数量可能随统一刷新快照变化 | 不同截图可能呈现不同数量 | 同批截图锁定统一刷新时点，并在 manifest 记录快照和状态 |

其中“证据等级治理”会影响客户认知，需要用户确认手册采用的临时口径。
