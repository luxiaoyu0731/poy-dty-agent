# Frontend Manager Workbench

更新日期：2026-06-17

## 定位

新版前端面向 POY/DTY 上游原料研究的日常使用者，不再把首页设计成工程调试台。主界面优先回答：

1. 今天该看什么？
2. 成本压力是否上升？
3. 哪些事件影响最大？
4. 哪些数据可信？
5. 哪些缺口需要补？
6. 下一步做什么？

所有页面继续调用真实后端 API，不引入 mock 数据。缺数据时显示缺口和下一步动作，不用占位数字替代。

## 页面结构

| 页面 | 主问题 | 主界面展示 | 高级详情 |
| --- | --- | --- | --- |
| 总览看板 | 今天该先看什么？ | 成本压力、来源覆盖、事件样本、预测记录、成本链、下一步动作 | 连接状态、来源边界 |
| 原料链路 | 哪一段正在传导成本？ | 原油、石脑油、PX、PTA、MEG、POY、DTY 价格、日期、涨跌、口径 | 观测明细、来源边界 |
| 事件新闻 | 哪些事件影响判断？ | 中文摘要、来源、时间、模型方向、证据等级、原文链接 | 更新记录、文章线索、引用与反证 |
| 行情观测 | 价格是否支持成本上行？ | 关键价格、日期、变化幅度、口径、历史对照入口 | 历史价格对照 |
| 预测复盘 | 模型判断准不准？ | 命中率、已评分、待评分、错判原因、价格验证状态 | 证据快照、记录关联、反证 |
| 数据来源 | 数据够不够支撑判断？ | 核心来源、新闻源、行业观测、缺口、下一步动作 | 单源更新、CSV 导入、采集健康记录 |
| AI助手 | 用当前证据解释什么？ | 建议问题、回答、证据概览、证据明细 | 来源边界与引用规则 |

## 组件系统

新增或强化的组件：

- `PageDecisionHeader`：每页顶部的主问题、标题、摘要和真实操作按钮。
- `MetricTile`：总览核心指标，一张卡只回答一个问题。
- `SignalCard`：表达重点信号和下一步动作。
- `PriceTickerCard`：展示价格、日期、变化幅度、单位和口径。
- `EventInsightCard`：表达事件标题、中文摘要、方向、证据和原文入口。
- `SourceReadinessCard`：表达数据覆盖和缺口。
- `EvidenceDrawer`：承载技术记录、引用细节和高级字段。
- `ActionChecklist`：展示每日处理顺序。
- `EmptyInsightState`：业务化空状态，说明缺什么真实数据。
- `CompactTable`、`TimeWindowFilter`、`PriceTrendMiniChart`：为后续行情和复盘页面继续压缩信息密度预留。

## 后端信息隐藏策略

默认隐藏：

- `source_id`
- `doc_id`
- HTTP 状态码
- provider/model/token
- robots/cursor
- CSV 表头和字段校验细节
- HTML 原文和抓取审计

这些信息仍可在“高级详情”或数据管理员工具中查看，用于本地排错和审计，但不作为经理人主界面信息。

## 可用性原则

- 每页保留一个主动作，少量次级动作。
- 所有按钮必须真实可点击；不可用时显示 disabled 或明确说明原因。
- 新闻必须有中文摘要和原文入口。
- 行情价格必须有价格、日期、涨跌、口径。
- POY/DTY 始终标注为非成交型现货评估价。
- 空状态不显示 `--`，必须说明缺什么数据和怎么补。

## 当前边界

- 当前视觉仍是深色专业工作台，不做营销页或大屏炫技风格。
- 价格和新闻的时效取决于真实数据源可用性。
- 数据管理员工具仍保留在前端，但默认折叠，供本地研究和维护使用。
