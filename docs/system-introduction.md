# POY/DTY 上游原料智能 Agent 系统介绍

面向职业经理人的读法：这个系统不是一个“自动喊涨跌”的行情终端，而是一个把公开信息、行业观测、新闻事件和 AI 证据链组织起来的研究工作台。它的目标是帮助管理者更快判断 POY/DTY 上游原料成本压力正在增强、减弱，还是证据不足。

## 系统解决什么

POY/DTY 的经营判断经常被上游原料链、国际原油、航运、制裁、装置检修、宏观金融和国内政策同时影响。传统做法依赖人工翻新闻、看表格、记笔记，容易出现三类问题：事件太多、证据分散、事后复盘困难。

本系统解决的是“把影响成本压力的线索变成可复盘证据”的问题：

- 把原油、石脑油、PX、PTA、MEG、POY、DTY 放在同一条传导链里看。
- 把新闻从原始文章整理为事件簇，并标注来源等级、影响方向、反证和证据质量。
- 把预测写入账本，后续用真实价格窗口复盘，而不是只保留口头判断。
- 当数据缺失时显示缺口和低置信状态，不用模拟行情填满页面。

一句话：它服务“上游成本压力判断”，不承诺预测 POY/DTY 成品成交价。

## 每天怎么看

建议每天按 15 分钟节奏阅读：

1. 先看“总览看板”：确认今日成本压力、数据置信度、缺口提示和高优先级事件。
2. 再看“原料链路”：沿原油 -> 石脑油 -> PX -> PTA -> MEG -> POY -> DTY 检查压力从哪里来。
3. 打开“事件新闻”：只先看精选事件，不急着看全量抓取列表。
4. 进入“证据知识”或“AI 助手”：让系统解释一条事件为什么利多、利空或中性，并查看引用的 doc_id。
5. 到“行情观测”：确认 Brent/WTI、PX/PTA/MEG、POY/DTY 的价格层级和新鲜度。
6. 重要判断写入“预测复盘”：记录方向、置信度、依据和反证，等待到期后复盘。

管理层会议里可以只问三个问题：成本压力变了吗？证据来自哪里？哪些结论仍然不能用来决策？

## 总览

总览页是日常入口，回答“今天是否值得提高警惕”。它聚合：

- 成本压力指数和信心等级。
- 关键数据层是否齐全，例如公开市场观测、行业观测、事件观测。
- 近 24 小时精选新闻事件。
- 需要人工补录或复核的数据缺口。
- 已写入预测账本的近期判断和到期复盘状态。

总览里的空值也是信息：如果行业观测缺失，系统会降低置信度，而不是把旧数据或模拟数据当成真实行情。

## 原料链路

链路从更上游的原油开始，到下游的 POY/DTY 结束：

```text
原油 -> 石脑油 -> PX -> PTA -> MEG -> POY -> DTY
```

这条链路帮助管理者区分“压力源”与“结果”：

- 原油、OPEC、EIA、制裁和航运事件通常先影响风险溢价与石脑油。
- PX、PTA、MEG 更接近化工供需和装置状态。
- POY/DTY 位于更下游，公开可得数据更可能是评估价、基准价或人工录入观测。

系统会把事件、价格和行业观测挂到这条链上，便于看到传导路径是否闭合。

## 新闻

新闻雷达不是通用新闻站，而是 POY/DTY 上游成本事件雷达。它默认展示精选事件，保留全量候选用于复核。

新闻处理流程是：

```text
来源登记 -> 抓取运行 -> 原文入库 -> 候选事件提取 -> 去重聚类 -> 打分分类 -> AI 影响推理 -> 人工复核 -> 精选时间线/日报
```

系统按来源分层：

- A 级：官方、交易所、政府和国际组织，作为事实锚点。
- B 级：准官方、行业组织、企业公告和港口海事公告。
- C 级：公开媒体、RSS、GDELT、Google News 等发现源，只做发现和交叉验证。
- D 级：人工笔记、Computer Use 观察、内部整理，只做弱信号。

精选事件会给出推荐理由、影响链、反证和证据等级。C/D 级来源不能单独生成高置信结论。

## RAG

RAG 是系统的证据检索层。AI 助手回答问题前，会先从知识图谱、新闻文章、新闻事件簇、市场观测、行业观测、事件观测和预测账本里检索证据。

管理者需要关注三件事：

- 回答是否引用了真实 `doc_id`。
- 事实、推断和反证是否分开。
- 证据是否满足当时可见，即不能用未来新闻、未来价格或事后复盘结论倒推过去判断。

事件方向的正式口径是 LLM/RAG 判断。历史关键词或规则方向可以保留为审计字段，但不能进入最终预测、权重调参或命中率统计。

## 价格分层

不同价格的可靠性和用途不同，不能混在一起看。

| 层级 | 示例 | 用途 | 管理提示 |
| --- | --- | --- | --- |
| 交易所/官方/免费 API | Brent、WTI、EIA、FRED | 宏观与原油基准 | 可作为较高置信价格锚点 |
| 交易所或公开代理行情 | Sina PX/PTA/MEG 主连、东方财富备用核验 | 化工链中间品参考 | 需看来源、延迟和口径 |
| 公开页面现货评估 | POY、DTY 公开基准价/评估价 | 下游观察和回测代理 | 不是逐笔成交价 |
| 手工行业观测 | CSV、OCR、人工笔记 | 补缺口、做弱信号 | 必须保留来源和复核状态 |

价格层级的核心原则是：越接近公开评估和人工录入，越要降低自动化结论的置信度。

## POY-DTY 非成交评估价

系统明确把 POY/DTY 行标为“非成交型公开现货评估价”。这意味着：

- 它可以用于观察趋势、做研究代理、补全复盘窗口。
- 它不能等同于真实成交、订单价格或企业采购结算价。
- 它需要保留来源 URL、采集方式、规格说明、地区、单位、复核状态和备注。
- 当缺少未来 14 天真实或可接受代理价格时，回测窗口必须保持未评分，不能插值、猜测或倒推。

对经理人而言，POY/DTY 价格页更像“市场温度计”，不是“成交凭证”。

## 数据边界

当前产品目标是 0 成本 MVP，AI token 成本另计。数据边界如下：

- 可以使用免费公开源、免费 API key、公开 RSS、政府/交易所/组织页面和本地 CSV。
- 可以使用人工导入和 Computer Use 辅助整理公开可见页面。
- 不使用付费行情、付费新闻、商业终端、券商终端无人值守复制或未授权数据。
- 不绕过登录、验证码、付费墙、浏览器校验、CAPTCHA、许可证或访问控制。
- 商业新闻全文不能再分发，AI 摘要必须能回到原始 URL 或人工录入证据。
- 缺数据时降级显示，不用模拟数据填充图表或提高置信度。

这些边界不是技术细节，而是系统可信度的底线。

## 手工导入

手工导入用于补齐公开自动源覆盖不到的行业链数据、事件和新闻观察。常用入口包括：

- `POST /api/v1/imports/public-observations`
- `POST /api/v1/imports/industry-observations`
- `POST /api/v1/imports/events`
- `POST /api/v1/imports/news-observations`
- `POST /api/v1/data-snapshots`

模板在 `docs/data-templates/` 下，常用文件包括：

- `public_observations.csv`
- `industry_chain_observations.csv`
- `polyester_chain_observations.csv`
- `events_and_alerts.csv`
- `news_observations.csv`
- `poy_dty_spot_slow_queue.csv`
- `computer_use_slow_queue.csv`

导入后系统会返回接收行数、拒绝行数、校验错误和 `data_snapshot_id`。预测账本可以引用快照，方便之后解释“当时为什么这么判断”。

## 本地启动

前端：

```bash
npm install
npm run dev
```

默认前端地址：

```text
http://localhost:5173
```

后端：

```bash
cd server
uv sync --all-groups
uv run uvicorn app.main:app --reload --port 8000
```

前端连接后端：

```bash
VITE_API_BASE_URL=http://localhost:8000 VITE_API_PREFIX=/api/v1 npm run dev
```

DeepSeek、EIA、FRED 等 key 放在本地 `.env`，不要提交真实密钥。没有 DeepSeek key 时，AI 助手会使用本地回退并记录 trace。

## 分钟级采集

分钟级/近实时价格通道由 `server/scripts/price_minute_collector.py` 负责。它只访问公开免登录页面或 API，不绕过授权限制。

单次采集：

```bash
cd server
uv run python scripts/price_minute_collector.py --instruments Brent,WTI,PX,PTA,MEG,POY,DTY
```

循环采集：

```bash
cd server
uv run python scripts/price_minute_collector.py --loop --interval-seconds 60
```

其中 Brent/WTI 属于公开代理分钟行情；PX/PTA/MEG 优先使用 Sina 公开主连代理行情，东方财富作为备用核验，SunSirs 作为公开现货评估页；POY/DTY 是公开页面或人工慢队列得到的现货评估，不是分钟级成交数据。

## FAQ

### 这个系统能直接告诉我 POY/DTY 会涨还是跌吗？

不能这么用。它判断的是上游成本压力方向，并给出证据、反证和置信度；最终经营决策仍需要结合库存、订单、现金流、采购策略和内部成交数据。

### 新闻很多时，先看哪里？

先看精选事件和日报。全量候选用于复核、排查误报和追溯来源，不适合作为每日第一屏。

### 为什么有些高热新闻没有变成高置信结论？

因为来源、发布时间、正文证据、影响链和反证可能不完整。C/D 级来源、标题党、旧闻重复、缺少 A/B 级确认的事件，都应降低置信度。

### RAG 回答为什么强调引用？

因为系统要求每个事实句尽量绑定证据文档。没有引用的回答只能作为提示，不能作为正式判断。

### 回测命中率为什么会有未评分？

LLM/RAG 回测只在 Brent、WTI、POY、DTY 都有完整未来 14 天价格覆盖时计入 hit/miss。缺少未来价格时保持未评分，避免偷看未来或编造后验。

### 手工数据会不会污染系统？

手工数据可以进入系统，但要保留来源、录入方式和复核状态。D 级人工观察默认是弱信号，不能单独推高结论置信度。

### 什么时候应该停止自动抓取，改走人工流程？

遇到登录、验证码、付费墙、浏览器检查、站点保护、授权不明或商业终端限制时，应停止自动抓取，改用手工导入、公开替代源或放弃该数据。
