# ADR 0006：当前来源质量与归档展示

日期：2026-09-10。状态：用户授权修复，待当前发布验证。

依据：price-news-source-audit-2026-09-10.md，用户要求全部修复并复审。

决定：使用 source-quality.2026-09-10.v1。产业缩写需语义上下文；每日核心候选需前一业务日截止至本期截止之间的出版证据；未恢复原始出版者的聚合URL不构成独立佐证。当前正式来源必须处于active状态。覆盖基于本期实际A/B事实引用，不再按目录已配置数量判定。

历史事件、摘要、证据、锚点及哈希不重写。读接口对不合格旧选题作明确quality redaction，返回展示集合及原因，payload_sha256仍指向原始归档。新摘要在冻结前执行同一质量门槛，并把规则版本放入cutoff manifest。无证据时允许空状态或降级，不用日期刷新、默认置信度、标题缩写填补事实。

来源目录的last_attempt_at/last_success_at/quality_status使用真实运行记录，遵守分页快照截止。配置启用、读取完成、相关内容产出、独立来源引用为不同概念。公网探针增加只读采集连续性检查，80%以上来源近两小时有完成读取且至少10源才通过，个别失败仍在运行表中可见；这不证明文章质量或长期SLA。

近期代理/公开参考报价单独显示原始观察日期、单位、来源链接，不拼接历史现货曲线。行业指标只有真实同口径公开观测可更新；没有来源时保持真实缺口。

兼容：现有API字段与工业情报v1 envelope不变；quality_status现有自由字符串增加not_observed/overdue/historical_only。语义更严格，消费者不能再把covered当配置状态。新增表格消费已有/prices/intraday。无依赖、schema迁移或生产历史修复。

回滚：切回上一完整前后端发布对并重启相关进程；不会恢复或修改数据库。前一版本会重新暴露旧质量缺陷，因此只有服务不可用时回滚。

验证：专项负例/正例、只读时间窗和来源健康测试、现有industrial API/brief/projection/market/news测试、隔离Playwright、前端构建，随后Chrome公网复审。自然日连续运行及外部403/连接问题保持未验证/外部缺口，不能承诺即时全部关闭。
