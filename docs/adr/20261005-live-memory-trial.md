# RAG 与反思同时接入未来发牌：未验收线上试运行

2026-10-05，操作员取消效果回放后，要求新增模块实际影响发牌；讨论假先例、旧反思负效应和同时变更难以归因的风险后，明确批准“都接上”。这项决定替代“回放过门后才启用”的运行开关限制，不替代科学效果验收。旧试验、旧冠军、新版结果不得混用；不得在简历宣称新增模块已带来增益。

## 行为与边界

- 三个独立环境开关默认均为0：AGENT_MEMORY_RECALL_ENABLED（查询）、AGENT_MEMORY_VOTING_ENABLED（合格案例入先验）、AGENT_REFLECTION_BACKGROUND_ENABLED（背景教训及新版蒸馏）。生产试运行设为1，各自可撤回。
- 召回案例要求原文与可见时刻早于事件时刻、后验已知、同价格序列/来源/单位/合同、三来源三不同正文同向互证。来源域名独立是保守代理，不能证明不同媒体的报道完全独立；此局限保留。
- 合格案例交给历史经验模型；只有实际引用的案例能提供对应品种和期限的支持数。混合旧案例/召回的模型合计数不可拆解，改用已验证组的最大支持数，不累加。品种研判和纯规则定案共用范围限制；定案重新核验链报告凭据。未知/降级召回和无引用不提供新增计票。
- 旧教训保留模拟来源标记；背景提示不得成为硬置信上限或方向命令。新教训只来自已结算且发生方向改写的格，引用具体样本及链工件。分析标签使用发行时冻结的价格波动带（D1保持0.5%；D7/D30取max(0.5%,0.5σ√期限)，σ为最近最多120日收益的稳健/标准差上界，至少30日，同源）。它只服务反思分析，不修改既有21格方向或OOS结算合同，也不宣称该参数为最优。
- 缺冻结分析带、同源历史或成熟样本时不蒸馏；不能从旧失真命中标签偷渡新教训。按结算时刻选最近7日样本，覆盖较早发行的D7/D30。最少20个合格改写格，最多3条/周、30条活跃；新教训发布精确到时刻，09:05不能进入当日08:00发牌。成功替换才原子到期旧教训，历史内容保留。
- 不重跑已取消的实验、不回写旧发行、不重启客户正式报告；18个后端节点、前端第19资源卡、R1-R5/O1和40 HTTP尝试级硬顶不变。无合格召回/失败/预算耗尽仍可沿价格基准发行。

## 可观测与回滚

链报告记录开关、未验收标记、召回凭据、教训ID/来源/策略；定案行附链run_id、冻结输入哈希、策略和分析带。对报告、图谱、雷达已有共享原文依据的消费保持不变，不将历史召回相似段落伪装成已核验当日事实。

先关闭计票/背景开关；需恢复版本时使用保存的镜像、源文件及前端制品。保留已发行账本和新旧教训原文；新版教训需在旧策略回滚时隔离，避免旧提示把新版背景假设视为硬规则。无数据库迁移。

## 验证

正例：真实三源召回入历史提示、同品种D7按R2改写、成熟改写格进入反思；反例：跨品种/跨期限、伪造ID、降级/未来源、缺冻结带、未成熟/未改写格、重复发布。全量后端、npm check、全量E2E、安全及发布就绪证据记录在独立任务包；测试通过仅证明机制，不证明预测改善。
