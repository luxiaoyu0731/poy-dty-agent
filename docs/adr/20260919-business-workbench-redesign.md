# 业务工作台改造与历史兼容边界

日期：2026-09-19。状态：本地实施；未发布。

依据是用户 DOCX 及后续批准的三张预览。软移除范围采用用户“你看具体情况”的授权，优先移除当前运行功能，保留历史追溯。

## 决策

- 前端保留现有 React/AntD/ReactFlow/MapLibre，无新增依赖。总览使用生成的独立插画资产，行情沿用图标库；Agent 的配色沿用历史业务分组，节点与状态仍来自实际 11 节点接口。
- 价格展示新鲜度独立于运行状态及预测置信度，使用已有来源发布预算，日期异常或未知来源不直接绿灯。该指标表示发布节奏，不保证“今日报价”。
- 研判报告使用持久化事实及分析，分离事实/推断/反证，引用编号与来源索引一致；不新增模型调用，不把信息报告提升为正式预测。历史报告内容与校验值不变。
- 地图使用锚点来源发生时间，未知时才使用精确发布时间，严格限制过去 24 小时；收录、修订不能刷新事件年龄。无精确时间不进入地图。
- 地点来自已有来源几何，或与事件证据关联且状态 completed 的摘要 location。匹配本地已核验地点表，否则只在唯一国家可辨认时用 Natural Earth 国家示意点。不能确定地点则不落点；多地点冲突不任选其一。
- 地图返回单事件，不再服务端选取聚合代表项；浏览器聚合后可展开全部成员。最多 1000 个候选，截断明确提示。定位资料随 macOS 发布包及后端 Docker 镜像一并携带。
- 每日摘要独立页面、客户端类型/请求与 hook 删除。后端 brief 产出仍是既有自动化与历史引用契约，不因删除页面而销毁。
- dce_meg/ccf_dom_daily/ccf_average_price/ccf_manual_export 不再运行注册；DCE 网络适配器、密钥配置、示例主机白名单删除。旧来源采集 URL 返回 404。历史原始记录、引用、归档、旧合同兼容字段/解释代码保留；不是全库字符串清零。

## 影响与回退

地图语义变化和来源目录条目减少已纳入接口测试与文档。没有生产数据迁移，没有删除真实历史数据库或索引。后端库存/开工历史兼容字段仍存在，当前前端不呈现退休指标。

工作区有大量既有未提交变更，禁止用整体 checkout/reset 回退。按任务清单撤销本次 UI、地图、报告、来源注册改动；恢复 DCE 适配器时也要恢复其原测试和凭据定义。若未来发布后回退，应使用当次核实存在的发布锚点，不引用旧交接文档中的版本号。

本地回归不替代新版公网验收、原生 Windows 检查或未来连续运行证据。未购买服务、未调用收费模型、未触发正式采集、未发布生产。
