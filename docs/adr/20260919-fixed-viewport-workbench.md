# 固定视口工作台布局

状态：用户已确认，2026-09-19。

以用户 Mac 审阅版为视觉基准。页面填满可用视口；长列表、对话和报告正文在组件内部滚动，价格趋势与流程图保留完整画布及放大/恢复入口。移除重复页头，状态、页面快照时间、本次读取时间和刷新控件放在侧栏底部。

同批处理经用户明确批准的地图依赖安全升级：MapLibre 6.10.0、react-map-gl 8.1.3。Worker 经 Vite 独立打包为同源 JavaScript，保留现有 CSP，不使用远程瓦片或放宽 Worker 策略。相关公告：https://github.com/advisories/GHSA-jrc7-96c5-q579 。

无数据模型、接口、自动化任务变更；不复制或重置生产数据库。发布沿用不可变版本与 current/previous 切换，回滚只回退代码版本。
