# ADR-0001：七品种正式预测合同

- 状态：Accepted
- 决策日期：2026-08-31
- 当前合同：`seven-product-forecast.v1`
- 取代范围：当前生产预测面；不改写历史 `phase-a.v1-v7`、旧 42 格批次或 legacy scalar 的审计事实

## 背景

旧合同把“POY/DTY 上游成本压力”当成唯一正式目标，并把产业链节点放入 14 节点、42 单元的内部批次。已确认的产品定义要求原油、石脑油、PX、PTA、MEG、POY、DTY 七个品种同等级预测，每个覆盖 D1、D7、D30，共 21 个正式预测单元。继续沿用旧合同会把内部节点判断误当成用户目标，并可能把旧标量或缺少模型证明的结果显示为正式预测。

## 决策

1. 当前正式预测集合严格为：`crude`、`naphtha`、`px`、`pta`、`meg`、`poy`、`dty`。
2. 当前正式期限严格为：1、7、30 日；21 个 `(target, horizon)` 单元缺一不可。
3. 每格必须同时保存连续点预测、区间、方向、置信度、数据状态、关键驱动、证据引用、模型版本、特征版本、标签版本、数据快照、评估版本和生成时点。
4. 方向由模型版本冻结的品种级中性带转换，不以简单正负零转换；阈值只能由训练/验证段确定，不能查看最终测试段后调整。
5. `formal` 只用于：当前合同、21 格齐全、point-in-time 数据合格、冠军模型已晋级、该格当前 OOS 证据通过且批次审计通过。其他结果只能是 `low_confidence`、`reference`、`degraded`、`insufficient_data` 或 `model_unavailable`。
6. 系统始终可返回最后价格不变基线或低置信参考，但不得把它升级为正式预测。
7. LLM 只解释数值结果和证据。LLM 失败不阻断数值预测；数值模型失败时不得由 LLM 补造价格或方向。
8. CCF 历史数据只读保留，可用于历史差异调查；不得成为新捕获、当前标签、当前特征或当前正式资格的来源。
9. 旧 Phase A 批次继续按原 schema 只读审计，API/UI 必须标为 `historical_legacy_contract`，不得映射为当前 21 格。
10. 2026-09-01 修订：DCE EG 当前采集按操作者决定软移除，历史合同仅作只读审计。操作者接受 SunSirs 中国乙二醇现货评估作为当前 MEG 标签源，并接受其非成交属性与 2013 方法文件当前适用性未独立复核的风险；这项来源决定不等于预测 OOS 晋级。

## 标签与点时合同

标签注册表是代码中的版本化合同，不从请求参数临时选择。每个标签条目必须冻结来源、指标、地区、频率、单位、时区、发布时间、`visible_at`、修订、缺失值和连续化规则。当前口径如下；标签源被接受只表示身份冻结，预测仍只有在注册表校验、历史覆盖和逐格 OOS 门禁通过后才可晋级：

| 目标 | 当前真实标签 | 固定语义 | 当前限制 |
| --- | --- | --- | --- |
| 原油 | ICE Brent 首行合约日收盘（`yahoo_futures_daily_proxy`，BZ=F） | 交易日、USD/bbl、与市场新闻和期货同口径；v5 起作为标签 | EIA Europe Brent Spot FOB 与市场口径长期偏离 15~25 USD/bbl，且整周历史为一次性回填，v5 起退为仅证据序列。v1~v4 已签发原油预测仍按 EIA 冻结身份结算，新签发不再使用该序列；日频口径新鲜度窗口为 4 天 |
| 石脑油 | 公开石脑油现货评估 | USD/mt、公开页面评估，不是逐笔成交 | 必须形成连续可回放历史，禁止用月度贸易量替价 |
| PX | CZCE PX 主力连续结算/收盘 | CNY/mt、交易所期货代理标签 | 冻结主力切换和节假日日历；不得以广义二甲苯替代 |
| PTA | CZCE PTA 主力连续结算/收盘 | CNY/mt、交易所期货代理标签 | 同上 |
| MEG | SunSirs 中国乙二醇现货评估 | CNY/mt、非成交型现货评估；公开方法口径为 GB/T 4649-2008 工业优等品、出库/库区自提/现款 | DCE 软移除；SunSirs 专项方法文件日期为 2013-11-01，当前适用性未独立复核；页面无行级发布/修订时间，只能以首次成功捕获作为保守 `visible_at`。标签源已接受，但预测仍须逐格通过 OOS 门禁才可 formal |
| POY | 涤纶 POY 公开现货评估 | CNY/mt、非成交型评估；固定产品族和规格聚合 | 必须补足自动、连续、同口径历史 |
| DTY | 涤纶 DTY 公开现货评估 | CNY/mt、非成交型评估；固定产品族和规格聚合 | 必须补足自动、连续、同口径历史 |

## 评估与晋级

- 使用 expanding/rolling-origin；训练、选择、最终测试严格按时间分离。
- `seven-product-oos-gate.v3` 在逐样本边界执行双时间门禁：目标业务日不得早于预测原点的信息截点，实际值必须在该截点后才首次可见；训练集仍只读取截点前已可见版本。同一次抓取回填的历史可在抓取后作为训练数据，但不会生成历史 OOS 样本。这样既不冒充旧预测，也不会让一次合法批量首采永久毒化后续真实样本。
- 每格至少比较价格不变基线和冻结的季节性基线。
- 主要价格误差相对最佳朴素基线改善至少 5%，方向准确率至少 55%。
- 每格单独报告有效样本量、不确定性、最差阶段、极端行情、结构变化和泄漏检查；总体平均不能覆盖失败格。
- 候选模型通过全部门禁后才能产生新的冠军版本；晋级是显式、可审计的仓库内状态变更，支持回滚。
- 任何一格证据过期、数据漂移、标签失效或朴素基线反超时，该格自动降级，不能拖累其他格的诚实状态。

## 存储与 API

新合同使用独立的版本化七品种预测/评估记录，不改变历史 Phase A 表的含义。当前读 API 返回明确 `contract_version`、`formal_status` 和 `status_reason`。写入口保持内部鉴权、幂等和 append-only；当前无 21 格合格批次时返回空正式列表及可解释参考结果，而不是把 legacy ledger 填进去。

## 回滚

回滚应用版本时，旧 release 只能继续读取其原生历史合同；不得把新合同记录降格转换成旧 42 格。新模型冠军回滚通过冠军指针/版本选择完成，不删除模型、评估或预测记录。
SunSirs 标签发布回滚只切换不可变 release 指针；已追加的 SunSirs revisions 不删除。旧 release 的 MEG 缺口合同不会读取这些 revisions，因此共享数据库保持向后安全。

## 后果

- 旧 Phase A 大量契约测试继续保护历史审计，但不再是当前产品完成线。
- 初期会出现“21 格参考可用、正式 0 格”的诚实状态，直到真实数据和 OOS 证据逐格通过。
- 21/21 通过和生产首次成功前，项目不能宣称 100/100。
