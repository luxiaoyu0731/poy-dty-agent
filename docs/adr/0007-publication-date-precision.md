# ADR 0007：保留来源出版日期精度

状态：本地实施，待测试及发布审核。
问题：公网最近100条工业条目13条published_at为空；投影明确丢弃来源日粒度日期，摘要准入因此可能误排官方新闻。
决定：单独published_date，不伪造时间或时区。日粒度按业务日期窗口准入，且收录时间必须在截止前；严格时间级字段继续带时区。无法得知源时区时不宣称小时级新鲜度。
接口：ItemRevision、ItemDetail增加可空字段；Claim仅接受可选字段，但本次不向已持久化claim新增字段，以兼容前版本回滚；新投影parser/payload manifest标注v2-date-precision。SQL结构无改动，字段保存在现有canonical payload。缺字段的旧payload保持原hash。
数据：只影响正常新投影；没有改写既有生产数据库或归档。历史重投影必须另外审核明确范围。
验证：日期、旧日、未来日、非法日期、精确时间、截止后的visible_at；API与投影回归。
回滚：退回前一代码；新增payload保留，旧API忽略额外内部字段；不删除任何历史记录。
