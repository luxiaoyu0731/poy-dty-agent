# 原文绑定的语义复核与逐项加载

## 决策与范围
操作员要求补齐证据核验和公网内容，并批准复用现有 DeepSeek，本任务总预算350元。
采用独立操作员工作任务处理近7日来源A/B的正文，不由页面请求触发；累计预算不按天重置。
不改变R1-R5/O1、已发行输入、账本、预测链40次上限或P2召回计票。

## 材料与推理的区别
确定性的英文商业原油库存、明确装置执行补入新的档案v4规则；v1/v2/v3历史档案仍按原政策重建。
AI输出逐字引句、主体、动作、供给/需求/库存变量与增减、条件、时期及出处。
程序校验来源哈希、原文子句归属、否定与传闻、独立可见时刻、时期、供需变量与价格压力符号。
供给增加与价格压力向上不是同一变量。进口来源替换不作为总需求增长。
语义复核仍为条件依据，不赋计票权，不证明事实真实性、因果效果或命中率。
已作出的政策决定可列为“已宣布·执行待核验”；未知发生日不以发布时间伪造。
如事件本句未写原料，需要同篇逐字范围引句和共同设施/地区实体；不能借LNG等品种的困难映射原油。

## API与界面
EvidenceDossierResponse新增semantic_reviews（默认空数组），只有当前品种视图读取。
已发行、事件、报告、回答和批次语境不注入后来复核；context_only与直接证据票数不变。
条件支持和条件相反分别列于关键依据区，展示条件及来源，与直接机制规则依据分开。
已核验直接依据优先分页，不被报价快讯挤到后页。
初始/后台加载逐字段显示；显式刷新继续原子恢复，行情价格与链视图保持一组提交。
证据页不依赖全局工作台的重聚合完成后才启动读取。

## 成本与失败
任务350元累计上限；每次HTTP前按输入UTF-8字节上界和2500输出token预留，失败不退还。
保守预留费率输入20/输出50元每百万token，高于本次已查直接服务公开费率；不是已确认账单。
沿用配置中继地址；不新增服务/依赖。密钥不输出，私有缓存正文不提交。
任何校验失败保留诊断，材料不转正；缓存读取不调用模型。
GitHub查看dateparser等，日期解析不能替代原文语义和预算核验，因此保留现有Pydantic/httpx体系。

## 验证与回滚
原文伪造、品种错配、方向反号、否定、计划、发生日、闭合报告期、上下游范围与冻结档案重建测试。
逐项加载测试保留慢请求、刷新原子性与行情快照一致性，不用降低断言消除回归。
生产回滚优先保存制品和镜像；移除语义复核目录配置即可关闭条件卡，旧API默认空数组兼容。
发布必须有本会话最终代码check、全量pytest/e2e及readiness审查；P2草稿不混入本批。

## 跨句关联补充
同篇明确群组成员/代词关联可经第二次独立模型请求复核，保留完整连接引句、候选哈希、来源哈希、模型时刻和否定结果。仅同地区不成立。仍是条件材料，不升级事实真伪或方向票数。
原文对齐仅允许空白与引号字形恢复，返回逐字原始片段；歧义、数字/词语修改拒绝。英文动作使用完整词边界，否定缩写同样拒绝。
“本周”只表示原发布地日历的周一至发布日区间，不推定唯一发生日或尚未完成的周末。混合原料政策显式提示总量不等于原油份额，执行待核验。
关系图以虚线绘制最多每侧三条条件关联，并与直接核验计数分开；未读到模型批次时显示无法核对，而非虚报合同缺失。
