## Accepted behavior

- Preserve decimal points, numeric grouping, signs, units, entity names and full
  dates. Support numeric and spelled-out English dates, unquoted direct denials,
  explicit date repositioning, and the narrowly equivalent Chinese action pairs
  发生火灾/起火 and 停止生产/停产. No general semantic inference is claimed.
- Separate denial candidates from linkable factual conflicts. Missing dates,
  unresolved subjects, speculative/negative propositions and uncertain
  attribution remain visible in internal counts with exclusion reasons. They
  never become counterclaims just to raise coverage.
- Read original text only from an existing accepted full-text summary with the
  current prompt, matching article/item/summary content version, and a summary
  generated by the cutoff. Recompute the stored-byte fingerprint. Keep the exact
  matched quotes in the immutable derived event claim and retain the original
  item-revision evidence edge. A matching passage elsewhere in a multi-topic
  article cannot contradict this event unless its fact contains that passage.
- Legacy ingestion hashed the complete fetched article but stored a 5,000-char
  prefix and a 200-char title. A recognized legacy prefix may supply discovery
  leads only. New normal ingestion separately fingerprints stored text, binds it
  to the existing full-content identity, and timestamps the proof. Existing
  content identities, observation dates and forecasts are not rewritten. A
  future fingerprint cannot qualify a past cutoff. Discard a clipped final
  sentence to avoid losing a qualifier or negation.
- Use existing append-only `intelligence_runs` records for atomic cursor state.
  Scan by stable event/item identity; for each event page, traverse every item
  page before advancing. Revisions cannot reorder the sweep. Item recency uses
  visibility, event recency uses last collection; already associated events and
  sources remain eligible for withdrawal checks. Dry runs do not move cursors;
  a failed evidence/cursor write rolls back the whole batch.
- Preserve existing source tiers, rights, temporal gates, withdrawal behavior,
  frozen reports/predictions and single-flight execution. No schema migration,
  model calls, new dependency, external retrieval or budget change.

## Metrics and target

The first pilot target is matched-pair recall >= 80% and precision >= 95% on
reviewed eligible evidence pairs. Recall is TP/(TP+FN), precision is TP/(TP+FP);
neither is the fraction of all events containing a counterclaim. Empty positive
denominators are unavailable, never 100%.

Qualification needs at least 30 independently reviewed real positive pairs and
100 negative/ambiguous pairs, deduplicated by underlying fact/source family and
separated from development examples. These are pilot point-estimate thresholds,
not a statistical guarantee. Report counts and uncertainty; a small synthetic
regression set or discovery recall cannot qualify production pairing accuracy.
Freeze eligibility and human labels before evaluation. An otherwise eligible
true contradiction missed because of paraphrase or language remains a false
negative; do not remove it from the denominator because the current rules fail.

The implementation still does not resolve unrestricted paraphrases,
cross-language attribution, undated claims or evidence that merely weakens a
business hypothesis. Those must be evaluated separately, not relabeled as
factual contradiction. A production matching-rate promise remains conditional
on a representative real-pair evaluation.

## Reuse, tradeoffs and rollback

Reviewed [pySBD](https://github.com/nipunsadvilkar/pySBD) (MIT, Python, established
commit history): useful for general sentence segmentation, but it does not
solve proposition identity or temporal attribution. No dependency is needed
for the bounded decimal/abbreviation correction. The inspected
[ambiguity-aware fact-checking project](https://github.com/ComplexData-MILA/ambiguity-aware-factchecking)
is a research evaluation pipeline with model/API integration and no confirmed
license in the inspected entry point; no source was copied or executed.
Maintenance/security suitability for adoption was not established. We retain
only the evaluation distinction between ambiguous claims and confirmed links.

Rollback restores the prior reviewed image and scoped source files. Existing
run records and added evidence remain readable under v1; v1 ignores the v2
cursor provider. No database downgrade or history deletion is required.
