# ADR 0009：聚酯库存/开工指标软移除

状态：已实施并部署。

问题：聚酯库存天数、开工率为行业调研数据，全市场仅付费商（隆众/卓创/化纤信息网系）提供结构化序列；
CCFGroup 未认证抓取已判定不可行（ADR-0008）。工作台继续展示 CCF 冻结历史会产生"指标仍在更新"的误导。

决定：按操作人 2026-09-12 指示，将 POY/DTY/PX/PTA/MEG 五个品种的库存、开工行业观察指标软移除：
- 工作台市场链不再读取、不再投影这两类序列；摘要显示"已软移除（ADR-0009）"及定性佐证说明；
- 两类指标不参与新鲜度/就绪（indicator_ready）判定；
- 历史数据库行只读保留，与 CCF/DCE 软移除同口径；恢复须另立 ADR。
边界：原油品种的库存/炼厂开工走 EIA 市场观测，仍为活数据，不在本决定范围内。
加工差不受本决定影响：已改为自有标签序列自算（0.855×PTA + 0.335×MEG 口径）。

接口：`/workbench/market-chain` 各品种 `inventory_summary`/`operating_summary`
`status="soft_removed"`（tag=已软移除），`data_freshness.categories` 对应项
`status="soft_removed"`；`data_coverage` 对应计数为 0。`quality_warnings` 不再为
软移除指标产生"未返回"告警。前端无必改项（按现有状态渲染）。

数据：未删除任何历史行；未变更采集调度（该两类本就无在跑采集）。

验证：市场链 28 项测试（含软移除专项：不再读取行业观察、摘要/新鲜度/覆盖计数、
告警清单）；全量后端回归通过；生产 smoke 门禁 30 项通过。
