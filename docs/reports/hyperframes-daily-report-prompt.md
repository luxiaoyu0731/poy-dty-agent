# Hyperframes 今日汇报视频 Prompt

把下面内容复制到 Hyperframes，用于生成 60-90 秒中文今日汇报视频。风格要求：深色金融终端感、清晰数据卡片、少量动效、不要夸张营销，不使用虚构价格和虚构新闻画面。

```text
请生成一个 60-90 秒的中文项目进展汇报视频，主题是“POY/DTY 上游原料智能 Agent 今日进展”。日期显示为 2026-06-13。

视频风格：
- 深色金融研究终端视觉，黑/深灰背景，青绿色与琥珀色强调。
- 使用简洁数据卡、代码片段、流程图、测试通过徽标。
- 节奏专业、克制，像个人研究系统的每日复盘，不要做成企业发布会。
- 画面比例 16:9，适合桌面汇报。
- 中文旁白，字幕同步显示，语气沉稳、有判断力。

视频结构：

1. 开场，约 8 秒
标题：POY/DTY 上游原料智能 Agent 今日汇报
副标题：新闻反向事件、抓取稳定性、行业手工模板、版本固化
旁白：
“今天把系统从能跑，继续推进到更稳。重点不是堆功能，而是让新闻判断更接近真实市场复盘。”

2. 核心修复一：新闻反向事件，约 15 秒
画面：左侧是冲突升级新闻，右侧是停火、复航、解除制裁、增产、库存增加等反向事件。
字幕要点：
- 新增风险缓和识别
- 停火、和谈、复航、解除制裁可判为利空
- 不再默认把所有制裁/航运新闻判为利多
旁白：
“上一轮中东复盘暴露出一个问题：系统对冲突升级很敏感，但对风险缓和不够敏感。现在停火、复航、取消打击、解除制裁、增产和库存增加都会作为反向事件进入判断。”

3. 核心修复二：抓取稳定性，约 15 秒
画面：新闻源列表 OPEC、EIA、OFAC、Treasury、State、EU、NDRC、NEA、UKMTO、MARAD，旁边出现 retry、allowlist、no relevant items、HTTP status 标签。
字幕要点：
- 补全官方源 allowlist
- transient timeout 自动重试
- 无相关内容不伪装成成功
- 失败记录更具体：HTTP status / Timeout
旁白：
“抓取侧补了官方源 allowlist，并加入临时超时重试。抓到网页但没有相关事件时，会标记为 no relevant items，而不是假装成功入库。”

4. 核心修复三：行业手工数据模板，约 12 秒
画面：CSV 模板字段滚动，旁边是每日手工填报清单：POY、DTY、PTA、PX、MEG、价差、装置状态。
字幕要点：
- 新增每日手工填报清单
- 允许空值占位，但不抬高置信度
- 全国口径优先，来源和 notes 必填
旁白：
“行业数据继续坚持零成本路线。模板只定义字段，不伪造价格。空值可以作为缺口证据进入队列，但不会抬高系统置信度。”

5. 质量门禁，约 15 秒
画面：终端测试结果卡片。
字幕显示：
- ruff check: passed
- backend pytest: 33 passed
- RAG eval: 6/6 passed
- AI eval: 21/21 passed
- frontend check: passed
- Playwright E2E: 3 passed
旁白：
“本轮质量门禁全部通过。后端测试扩展到 33 个，RAG 回归 6 过 6，AI 基线 21 过 21，前端构建和 E2E 也正常。”

6. 当前系统判断，约 15 秒
画面：流程图：新闻源 -> 事件聚类 -> RAG 证据 -> 成本压力指数 -> 预测账本 -> 价格复盘。
字幕要点：
- 个人本地研究版：可用
- 0 成本路线：成立，但有边界
- 分钟级商业行情和化纤现货实时仍需授权数据
旁白：
“现在系统已经是一个可用的个人研究 Agent。它能做公开源事件识别、RAG 证据解释、预测账本和价格复盘。但它仍不替代商业行情终端。”

7. 结尾，约 8 秒
画面：版本提交卡片和下一步清单。
字幕：
下一步：source-specific parser、风险缓和事件权重、行业真实录入、视觉回归审阅。
旁白：
“今天的版本已经固化。下一步继续提升各官方源解析器，并用真实行业手工数据训练自己的判断闭环。”

禁止事项：
- 不要生成虚构新闻标题。
- 不要生成虚构 Brent、WTI、PX、PTA、MEG、POY、DTY 价格。
- 不要暗示系统已经接入付费商业数据。
- 不要说已经完成生产发布。

输出：
- 生成一支 16:9 横版视频。
- 保留中文字幕。
- 使用清晰的数据卡片和流程图画面。
- 结尾显示“0 成本个人研究版，持续迭代中”。
```
