# 预测准确率优化计划 —— 现有数据规模上的隔离实验框架

状态：**计划（未授权执行 P1 之后的条目）** ｜ 修订：2026-09-30 晚（应"在现有数据规模上做隔离实验，不等自然日沉淀"重新设计）
前置红线：不改变 1/7/30 天合同、08:00 调度、正式/观察级定义与门禁阈值本身；生产账本只读；所有实验在影子/隔离库中进行。

## 0. 核心思路转变

原计划假设"一个方案 = 等一个自然日看结果"。本修订以**回溯式隔离实验**取代：

```
现有可复现数据
  ├─ 30 个已发行批次（2026-09-01 起）+ 342 个已结算格（方向命中 53%）
  ├─ 价格观测 11.3 万行（原油 1982 年起 6.2 万行；MEG/PX/PTA 2010 年起；短标签 2024-12 起）
  ├─ vintage 导出器（export_vintages：任意历史时点的冻结输入，点时可复现）
  └─ 影子运行器（run_prediction_shadow.py：隔离账本，不触生产库）
```

任何候选改动（特征/方向规则/中性带/模型变体）都在**同一段历史区间上回放**，
与现行基线在**完全相同的样本对**上打分——一个下午出一个含置信区间的结论，
把"等自然日"变成"等 CPU 分钟"。

**统计口径**：样本 30 天 × 21 格 ≈ 342 结算格，但**逐格**看仍少（多数格 n<20）。
因此隔离实验的评估单位是**同一品种跨 horizon 合并**或**跨品种同 horizon 合并**的
分组指标，并报告 bootstrap 置信区间（重抽 1000 次）。回放区间内的"有效样本"
以实际可得为准——这正是隔离实验的第二产出：**先量化每个格到底有多少可学样本**。

## 2. 隔离实验基础设施（E0，先建框架再做实验）

全部复用现有部件，无新依赖：

1. **回放工作台**（新脚本 `scripts/experiments/replay.py`，只读生产库）：
   - 输入：品种 × horizon × 候选改动标识 × 回放区间（如 09-01 → 09-30 的 30 个已发行批次）；
   - 对每个历史发行时点：`export_vintages(as_of=发行时点)` 重建冻结输入 → 现行管线出**基线预测** → 同输入喂给**候选变体**出影子预测；
   - 两者都与账本里的不可变实际值配对，输出逐样本对比表（MAE、方向命中、bootstrap CI）。
2. **变体注册**：候选改动以纯函数/参数形式挂在影子管线（如 `direction_rule=point_sign|interval_mid|band_breakout`、`neutral_band=±0.5%|±1%|自适应`），同一份输入可跑全部变体；
3. **产出**：`/data/experiments/<id>/result.json`（逐样本明细 + 分组汇总 + CI），报告文件与图表入 `docs/experiments/`。

验收：E0 完成后，回放 30 个批次的现行基线，其指标与生产 OOS 评测一致（±舍入）——证明回放器无损。

## 3. 实验清单（每个都在 E0 上运行；预期一个下午出结论）

### E1｜原油 30d 方向判定审计（P0，最高价值）——✅ 已完成（2026-09-30）

工具已入库（`scripts/experiments/replay.py`），完整结果见 `docs/experiments/20260930-e1-direction-rules.md`。定论：

- 原油 7d 的 0% 命中是中性带吞没（23 结算格全 neutral vs 实际全 up），±0.25% 断点单格 74%；
- 但全样本（n=341 配对）McNemar 精确检验 p≈1.0：带宽变更 = 样本内噪声换位，**不上线**；
- 原油 30d 方向 30% 是模型对 30d 方向的真实判别力不足，非可调参修复；
- **定论：现有 30 天数据规模下，规则/标定层面无可统计显著改善的杠杆。主路径 = 样本自然积累
  （见 E5），待样本翻倍（约 2026-12）用同一工具重跑本审计。**

### E2｜原油 7d 反向噪声溯源（诊断性）

- 7d 方向 26% 显著低于随机：检查该 horizon 的特征符号与权重是否被 30d 趋势特征污染；
- 产出：特征-方向相关性表；若确认污染，修复属于 bug 修复而非算法变更。

### E3｜中性带宽度标定（PX/PTA/MEG 1d）

- 这三个 1d 格方向准确率 57-80% 已经过线，卡在误差与样本；
- 回放不同中性带宽度，观察误差提升是否转正（当前 −8%～−25%）；
- 通过标准：某宽度使同区间误差提升 ≥5% 且方向不退化 → 记录为 P2 候选（需另行授权上线）。

### E4｜短周期基线竞争分析（预期管理，不产改动）

- 用回放数据量化：1d/7d 朴素基线的 MAE 与最优可实现 MAE 的差距分布；
- 产出：一份"短周期格理论上限"说明，用于向用户解释为什么这些格的评分天花板低。

### E5｜样本地图（零实验，纯统计）

- 对每个格输出：可回放历史长度、逐 horizon 有效样本数、按当前采集速度的"预计达标日期"；
- 供运营预期管理：POY/DTY 1d 约在 2026-12 达 n=20；PX/PTA 7d 约 2027-01。

## 4. 明确不做

- 不在生产账本上 A/B（生产账本只读，影子库隔离）；

- 不引入未在模型注册表声明的新模型类别或外部特征源（E 系列只动规则与标定参数）。

## 5. 度量与上线门槛

- 任何变体进入生产的门槛：OOS 重放在**完整区间**上三门槛不退化、方向/误差至少一项显著改善（CI 不含 0）；
- 上线路径：影子结论 → 你确认 → 窄发布（与既往同流程）。
